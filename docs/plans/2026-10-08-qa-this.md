# qa-this Plan

Spec: `docs/specs/2026-10-08-qa-this.md`
Goal: add `/real-skills:qa-this`, QA on a non-production environment with script-chosen methods, script-recorded results, evidence comments on tickets and PRs, and one short report file.
Verify: `node --test skills/*/scripts/test/*.test.mjs && bash skills/changelog/scripts/test/release-ranges.test.sh && claude plugin validate . --strict`
Constraints:
- Node 20+, no dependencies, ES modules, one JSON object per harness call (as `wtf.mjs`, `review.mjs`).
- Skill must work installed as a single folder: it carries its own copies of shared files; `sync.test.mjs` keeps them identical.
- Every Jev question ships in `UNCALIBRATED` with a `kase(...)` record and a `catalog.mjs` line.
- Never production. Never a tracker write other than the comment and the opt-in attachment.
- Version `0.8.0` in both manifests. If `main` takes `0.8.0` first, use the next minor.
