# promote Plan

Spec: `docs/specs/2026-10-09-promote.md`
Goal: add `/real-skills:promote`, a gated promotion of one environment's branch into the next (preflight, infra check, PR, merge, watch, verify) driven by a harness, with the repo's stages stored in `.claude/promote.json` and three shadow Jev questions labelled by setup.
Verify: `node --test skills/*/scripts/test/*.test.mjs && bash skills/changelog/scripts/test/release-ranges.test.sh && claude plugin validate . --strict`
Constraints:
- Node 20+, no dependencies, ES modules, one JSON object per harness call (as `check.mjs`).
- Works installed as a single folder: carries its own copies of `jev.mjs`, `redact.jq`, `calibration.mjs`, `report-style.md`; `sync.test.mjs` keeps them identical.
- Every Jev question ships in `UNCALIBRATED` with a case record and a `catalog.mjs` line. Jev decides no gate.
- The only writes: one PR (`open`), one merge (`merge`). Both need `--confirmed`. No `--admin`, `--auto`, `--delete-branch` anywhere in the skill.
- A gate that could not be read is `unknown`, never `pass`.
- Version `0.10.0` in both manifests.
- Commits only when the user asks.
