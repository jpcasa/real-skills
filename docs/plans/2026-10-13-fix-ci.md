# fix-ci Plan

Spec: `docs/specs/2026-10-13-fix-ci.md`
Goal: `/real-skills:fix-ci` reads a pull request's failed checks, classes each failure, reproduces and proves the code ones with a script, pushes one commit per round after a yes, and watches CI for up to three rounds.
Verify: `node --test skills/*/scripts/test/*.test.mjs && bash skills/changelog/scripts/test/release-ranges.test.sh && claude plugin validate . --strict`
Constraints:
- Node 20+, git 2.38+, `gh`, `jq`. No dependencies. No YAML parser: the command comes from the job log.
- Every command prints one JSON object.
- No force flag on any push. `--force` appears only on `git worktree remove`.
- The commit is built with a temporary index and `commit-tree` from the head plus the listed files only: what a command left behind never reaches it. HEAD moves only after the push.
- A tracked config file is read as the base branch has it; one the pull request adds is not used.
- `gh` writes exactly one thing: `run rerun --job`. Everything else reads.
- `jev.mjs`, `redact.jq`, `calibration.mjs`, `glob.mjs`, `scrub.mjs`, `report-style.md` are copies; `sync.test.mjs` pins them.
