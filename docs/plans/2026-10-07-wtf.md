# wtf Plan

Spec: docs/specs/2026-10-07-wtf.md
Goal: ship `/real-skills:wtf`, read-only bug-report triage whose citations, deploy skew, verdict rules and budgets are enforced by a script.
Verify: `node --test skills/*/scripts/test/*.test.mjs && bash skills/changelog/scripts/test/release-ranges.test.sh && claude plugin validate . --strict`
Constraints:
- Node 20+, zero npm dependencies, ES modules, one JSON object on stdout per call.
- `skills/wtf/` is self-contained: own `jev.mjs`, `redact.jq`, `paths.mjs`, `report-style.md` (identical copies, pinned by `sync.test.mjs`).
- The script never trusts a claim it can check: `verdict` re-verifies citations, recomputes skew, and reads the reproduction result from run state, not from its input.
- Jev input is built only from the scrubbed symptom line, prior-ticket titles and expected/actual lines. All Jev questions ship in `UNCALIBRATED`; when calibrated they may only remove support for a verdict, never add it.
- Nothing specific to the private repo the original skill came from: no hostnames, ids or product vocabulary.
- Reproduction refuses production hosts and an empty `production_hosts`.
